# === FinPROga - финансовая программа ===
Программа на языке программирования Python. Верный помошник
в финансовой области. Калькулятор расчёта кредита/ипотеки и конвертер валют.


## Что нового: Обновление 1.3.0 (STABLE)
- Украшен интерфейс программы с помощью цветов и эффектов (верхний блок кода)
- Исправлено БОЛЬШОЕ количество багов (ошибок) такие как: (Ошибка при получении данных из API
в режиме (online), курса и перевода валют. Падение программы из-за встроенного выхода ctrl + c во всех местах программы. Исправление ошибки, при которой из-за слишком маленького платежа программа падала с ошибкой в калькуляторе расчёта кредита/ипотеки.)

## Возможности
Модуль 1:
- Калькулятор расчёта для кредита/ипотеки
- Удобный и качественный ввод данных с защитой от ошибок
- Таблица погашения кредита/ипотеки по годам
- Возможность сохранения результата расчёта в личный файл

Модуль 2:
- Просмотр курса и конвертация валют
- два режима работы на выбор: (online/offline)
- Подключение к API ЦБ (аналог) в online режиме, для точных данных
- Удобный и качественный ввод данных с защитой от ошибок


## Как запустить
1. Установите Python 3.14.3 или выше
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите программу: `python FinPROga.py` ИЛИ через треугольник в правом верхнем углу.
